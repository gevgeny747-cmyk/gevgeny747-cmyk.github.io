📚 Чистый HTML решение:

Для создания раскрывающегося текста используется стандартная связка тегов <details> и <summary>. Код работает во всех современных браузерах автоматически.

<details>
  <summary>Нажми, чтобы прочитать скрытый текст</summary>
  🎯 Поздравляем! Текст успешно раскрылся без единой строчки JS-кода.
</details>
